# Syllabes CP

Projection de syllabes en classe de CP, générées à partir des sons déjà vus.

- `npm run dev` : développement
- `npm test` : tests du modèle
- `npm run build` : produit `dist/index.html`, un fichier autonome (polices et scripts inclus) à ouvrir dans Chrome, depuis un serveur ou directement depuis le disque / une clé USB.

Les séances sont sauvegardées dans le localStorage du navigateur quand il est disponible, en mémoire sinon.

Polices embarquées : [Andika](https://software.sil.org/andika/) (script, capitales) et [Marelle](https://marelle.forge.apps.education.fr/) (cursive, Ministère de l'Éducation nationale), toutes deux sous licence SIL OFL 1.1.
